# PSRCHIVE User's Guide: Viewing Data

In any experiment that involves data analysis, the first step is looking
at the data.

1. [Metadata](viewing/metadata.md):
   Ensure that the data are accurately described.
2. [Data](viewing/data.md):
   Ensure that the data look as expected.
3. [Calibrator Data](viewing/cal/index.md):
   Plot the data or the solution derived from them.
