# PSRCHIVE User's Guide : Calibrating Data

## PSRCHIVE User's Guide: Calibrating Data

Here, calibration is divided into two stages: polarimetric and flux
calibration. For some instruments or experimental designs, depending
on the available constraints, flux calibrator observations are
required in order to perform the best polarimetric calibration. This
is discussed in more detail in the following sections.

1. [Overview](calibrating/overview.md):
   Overview of Calibration.

   - [Polarization](calibrating/polarization.md):
     Produce calibrated Stokes parameters.

     - [Flux](calibrating/flux.md):
       Measure the flux of the source in Janskys.
