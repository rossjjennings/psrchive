# User's Guide: Core Applications

The core applications provide access to the vast majority of PSRCHIVE functionality commonly used for inspection,
visualization, and reduction of pulsar data. Core applications make
extensive re-use of modular interfaces; for example [psrplot](../../psrstat.md) can employ the [psrstat](../../psrstat.md) parser to annotate plots and
the [psrsh](../../psrsh.md) command language interpreter to
preprocess the data. Typical features of the core applications
include

* [Standard Command Line Options](options.md)
  + [Standard Preamble](options.shtml.html#preamble)
  + [Standard Preprocessing](options.shtml.html#preprocessing)
  + [Standard Output](options.shtml.html#output)
* [Evaluation of Mathematical Expressions](evaluation.md)
