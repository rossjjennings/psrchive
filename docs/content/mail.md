# PSRCHIVE Users Mailing List

To receive occasional emails regarding available updates, significant
bug fixes, and new features in the PSRCHIVE software,
please subscribe to the
[psrchive-users mailing list](http://lists.sourceforge.net/lists/listinfo/psrchive-users).

## PSRCHIVE on Twitter

For more frequent updates (ideas, plans, bug fixes, etc.) follow
[PSRCHIVE on Twitter](http://twitter.com/psrchive).
