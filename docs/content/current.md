# PSRCHIVE: Git Access

## Git Instructions

### Anonymous Git Access

The latest version of PSRCHIVE can be copied
from the Git repository (read-only access) by running the following command

```
git clone git://git.code.sf.net/p/psrchive/code psrchive
```

After successfully downloading the code, follow the
[Build and Installation](current/build.md) directions.
